# Project Timeline

This page separates **when the work happened** from **when it was organised into public GitHub repositories**.

The public repositories were consolidated in October 2026 for documentation, reproducibility, and portfolio review. They should not be read as evidence that each project began in October 2026.

| Period | Development |
|---|---|
| **April 2025** | This GitHub profile was created. |
| **2025** | Computational music research developed through the Wolfram Summer Research Program, exploring ancient Greek tuning systems with mathematics and code. |
| **January-April 2026** | Sahitya was piloted as a structured-literacy programme, combining phonics, rhythm, repeated practice, and low-friction delivery. |
| **2026** | Dementia-assessment research expanded into questions about language, cultural context, and the design of a multilingual ADAS-Cog workflow. |
| **2026** | Smriti developed from dementia-care research into an experiment in familiar voice, family context, and low-friction daily support. |
| **September 2026** | Smriti entered public-facing testing and launch work around World Alzheimer's Month. |
| **October 2026** | The separate project repositories were consolidated publicly on GitHub so the work could be inspected, demonstrated, and documented more clearly. |

## Why the dates matter

The chronology is part of the work.

The projects did not appear fully formed. A research question led to an experiment; an experiment exposed a design problem; a design problem became a prototype; field use created new questions.

GitHub is therefore being used here as a **public documentation layer**, not as a claim that all of the underlying research, pilots, writing, or project development originally happened inside these repositories.

Where current public demo code was added later, individual repositories say so explicitly.
